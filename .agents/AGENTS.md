# Ahmed Website KSA — Agent Rules

## Git Rules

- **Do NOT run `git commit` or `git add` automatically**: The user will manually review code changes and commit them to branches.
- **Never run `git reset --hard`**: It permanently destroys uncommitted work. If undo is needed, let the user know or ask first.

## Code Editing Rules

- **Never Use Destructive Regex on CSS/JS Files**: Never run a PowerShell or shell command that performs broad character-level substitution across files. Target specific property names and verify carefully.
